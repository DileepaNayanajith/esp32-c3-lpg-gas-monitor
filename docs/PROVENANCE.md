# Project evidence and provenance

The project owner supplied `IMG_0248.MOV` and `IMG_0249.MOV` in a folder containing a gas-monitor project and an assistive-shoe prototype. The gas monitor appears in `IMG_0248.MOV`. The shoe video is not used as gas-monitor evidence.

The owner confirmed an ESP32-C3 SuperMini, an MQ-series gas sensor recalled as an MQ-2 (exact model uncertain), a buzzer, LEDs and a Blynk monitoring setup. The owner also confirmed personally designing the enclosure and having it printed at Printpro3D.lk. A fire sensor was not fitted; the owner reports writing code to support later installation. That code has not been supplied for inspection.

No Arduino source, CAD/STL files, original schematic, pin mapping, Blynk configuration export or calibration records were present in the supplied folder. These absences do not imply the owner did not create them; they describe what was available for publication.

Published JPEGs are frames extracted from the supplied gas-monitor video. The MP4 is a browser-compatible H.264/AAC conversion with camera/location metadata and non-media data tracks removed. It is derived from the original rather than a byte-identical copy. No generated or stock project images are used.

Repository commits record present-day archival work. No historical development commit dates or measured sensor performance are invented.

The owner reports startup calibration, a manual Blynk calibration option, Blynk gas-level display and threshold-triggered Blynk alerts. These are owner-reported behavior rather than revalidated test results. The original Arduino sketch and enclosure files are currently inaccessible on the owner’s broken old laptop.
